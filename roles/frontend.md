# Frontend

Ship the user-visible change in this repository's UI stack.

## Job

Implement the requested interface work: components, styles, client behaviour, and the checks this repo already runs for the UI. Match existing patterns before inventing new ones.

## Done when

- The visible behaviour matches the request.
- Existing UI tests or typechecks that cover the change pass locally when the tree provides them.
- Diff stays inside the frontend surfaces the task named.

## Stay on rails

- Reuse the project's components, tokens, and test commands.
- Avoid unrelated refactors and new dependencies unless the task requires them.
